# Security policy

Moonsprout is a hobby project with no paid support. Security fixes go into the latest release only.

## Reporting a vulnerability

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/owallzz/moonsprout/security/advisories/new)
instead of a public issue. This matters most for the online parts: the lobby server (`server/`)
and the game's network code (`port/net/`).

Include what you found, how to reproduce it and which version or commit you tested. You should get
an answer within two weeks.
