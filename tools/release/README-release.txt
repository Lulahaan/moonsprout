Moonsprout - a native PC port of Pikmin 2
https://github.com/owallzz/moonsprout

Moonsprout needs a disc image of Pikmin 2 (USA, GPVE01) that you dumped from your
own disc. No game data is included. Start Moonsprout, pick Modern or Original, then
choose "Choose Disc Image" (or drop the image onto the window).

Settings and saves:
  Windows  %APPDATA%\mppm  (portable build: the "data" folder next to Moonsprout.exe)
  Linux    ~/.local/share/mppm
  macOS    ~/Library/Application Support/mppm
